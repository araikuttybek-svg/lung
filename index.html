Анатомия: оң өкпе — 3 бөлік, сол өкпе — 2 бөлік (жүрек ойығымен). Биофизика: RC-модель + Бойль заңы. Модельді саусақпен айналдырыңыз.

Модель қалай жұмыс істейді?

R·dV/dt + V/C = P(t)

  • Дем алу: диафрагма түседі, қабырғалар көтеріледі → көкірек көлемі артады. Бойль заңы (P·V = const) бойынша альвеолалық қысым атмосфералықтан төмен түседі, ауа өкпеге кіреді.
  • Дем шығару: пассивті — өкпенің серпімді қайтарымы V/C ауаны сыртқа итереді.
  • Созылымдылық C: ΔV = C·ΔP. Фиброзда C аз (өкпе қатты), эмфиземада C көп.
  • Кедергі R: Пуазейль заңы бойынша бронх радиусына R ∝ 1/r⁴. Астмада бронх тарылады → R өседі, дем шығару баяулайды.
  • Көлем көрнекілік үшін ×3 үлкейтіліп көрсетіледі. Дем алу : дем шығару = 1 : 2.
